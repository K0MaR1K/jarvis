# ДЖАРВИС — домашний ИИ-компаньон

Игорь · Холмск · «голова» — Honor 10 (COL-L29), Android 10 (EMUI 12), стоит вертикально.

## Что это
Старый телефон превращается в ИИ-компаньона: экран всегда горит, на нём лицо
в стиле Anki Cozmo — глаза моргают, следят за человеком через фронтальную камеру,
реагируют на руки. Дальше по этапам: голос, мозг (LLM), умный дом, память.

## Этапы
- [x] Этап 1 — ГЛАЗА: слежение за лицом, реакция на руки, сон/пробуждение
- [ ] Этап 2 — ГОЛОС: wake word + команды + ответ голосом
- [ ] Этап 3 — МОЗГ: LLM + каталоги событий/эффектов + самообучение правилами
- [ ] Этап 4 — РУКИ: Home Assistant (свет/ТВ/Tuya-выключатель)
- [ ] Этап 5 — ПАМЯТЬ: члены семьи по лицам + запоминание новых жестов

## Как получить APK (без всяких студий)
1. Обновления кода заливаются в репозиторий.
2. GitHub → вкладка **Actions** → верхний запуск **Build APK** → ждём зелёную галочку.
3. Внизу страницы запуска — раздел **Artifacts** → скачать **jarvis-apk** (zip, внутри `app-debug.apk`).
4. Скинуть APK на телефон, открыть и установить (разрешить «неизвестные источники»).

## Что умеет сборка этапа 1
- Запусти «Джарвис», разреши камеру — всё, лицо живёт.
- Подойди — глаза следят за тобой; подними руку — взгляд мгновенно перейдёт на неё.
- Никого нет 30 секунд — глаза тускнеют и прикрываются (сон); вернёшься — проснётся и моргнёт дважды.
- **Свайп влево/вправо — сменить мордочку** (Козмо, ЕВА, HUD Джарвиса, ХЭЛ, Би-Би 8), выбор запоминается. Живой каталог со стилями — в файле `faces-preview.html`.
- **Движок эмоций в духе Cozmo/Vector**: 10 эмоций (радость, грусть, злость, удивление, восторг, прищур, «думаю», любовь с сердечками, трупик с крестиками) — форма и наклон глаз едут пружиной с «боингом». Пробуждение: удивление → радость. Рука в кадре — удивление. От скуки — микромооды. **Долгое нажатие — демо-карусель эмоций.**
- Тап по экрану — отладочная строка: fps камеры, видит ли лицо/руку.

## Технически
Kotlin · CameraX 1.4.2 · MediaPipe Tasks Vision 0.10.29 (BlazeFace + HandLandmarker),
оба детектора офлайн на телефоне. Сборка: GitHub Actions, JDK 17, Gradle 8.10.2, AGP 8.7.3.

Структура:
```
app/src/main/java/com/kholmsk/jarvis/
├── MainActivity.kt          — экран, камера, разрешение
├── face/JarvisFaceView.kt   — глаза: анимация, моргание, сон
└── vision/VisionAnalyzer.kt — MediaPipe: лицо + руки из кадров камеры
```
